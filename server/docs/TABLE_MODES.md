# 桌子玩法（棋盤制／半合作桌）

> 從 `README.md` 拆出（2026-10-20）。機制本身的規格在 `packs/README.md`，劇本資料格式在 `docs/SCENARIO_FORMAT.md`。

## 棋盤制

`modules/hyakki_tower/scenarios/sannenme_no_onibarai/`（示範模組「百鬼塔」，原创世界观）是棋盘桌的参考实现：
世界观见该剧本的 `WORLD.md`，棋盘数据见 `board.json`。

**棋盘 = 14 节点图**（三座城镇＋荒野道＋塔正门／后门），塔内＝只能坐昇降機的竖层（6 层）。
世界设定与引擎机制的对照见 WORLD.md：

| 动作 | 做什么 |
|---|---|
| `move(target)` | 到相邻节点；荒野道要过**移动判定**（DC 随目标 danger）；塔外→塔内用 `enter` |
| `search` | 探索：找**昇降機入口**（入口用过即失效，要重新找）或拾到「有意义的记忆」 |
| `enter` | 用入口被传送进塔 1 階（该入口随即失效） |
| `ride(target)` | 昇降機上下楼（**唯一**楼层通路；本层小怪没清光就上不去） |
| `fight` | 打本层**小怪**（掉貨幣）；同层 BOSS 被击破会解锁隐藏层 |
| `pray` | 祈願箱换**神器**（骰值影响 tier）——代价是**扣记忆** |
| `buy` | 商店（ツルギ）用貨幣买；`bento` 这类是**塔内饮食**陷阱（扣记忆） |
| `exit_tower` | 出塔：塔内所得**被收夺**（貨幣清零，神器保留） |
| `rest` | 都市/村/港休息＝**回记忆**；在塔内 `rest` 则是「一体化」（扣记忆） |
| `game` | 游戏房街机＝回记忆 |

`memory`（记忆）是这个棋盘的第二条命：塔内每回合流失、祈願大扣、日常回补；
归零触发 **塔外**（记忆恢复＋被送回城）。

**换作品做新棋盘**：复制 `modules/<模组>/scenarios/<剧本>/` 目录 → 改 `board.json`（节点/边/roster/神器表）
与 `config.json`（规则/塔参数/记忆参数）→ 起服务。
**引擎与棋盘分离**：board.json 里没有一句代码，规则数值全在 config.json。


## 半合作桌（1 GM + 1 NPC + 4 玩家）

示範模組 的两个剧本（`sannenme_no_onibarai`／`scenario_b`）都启用 `semic` ⇒ 都是**半合作桌**：
剧本的 `TABLE.md` 是这张桌的说明书，`seats.json`（定员）/`goals.json`（私密愿望）/`clues.json`
（碎片与结论）是它的数据，`docs/PLAN_semi_coop.md` 是设计与取舍（尚有待拍板项，见 `docs/PENDING.md`）。

- **GM = GM agent**（拿 `table_gm` 工具：开景/收景、投放碎片、代投暗骰、NPC 视角包、代发 NPC 台词、结算、改判；**没有改数值的工具**）。
- **NPC = GM 的下游 agent**：不给桌子工具、不能查状态，只被动收 GM 喂的「视角包」，只回台词，由 GM 代发 → 视角稳定由结构保证。
- **玩家 2 人 + agent 2**：agent 每景 `act ≤1 / say ≤2`（人不受限）。
- **争抢**（同一祈願箱/同一碎片）走 `declare` → **收景时同时揭晓**（并列各骰比大小），不是先到先得。
- **碎片**：每次 `pray` 的代价以一枚碎片回到桌上，落在非请求者手上；`show`/`give` 留下来源链；被 ≥2 人看过就公开。
- **泄漏闸**：GM 叙述与 NPC 台词共用一个入口（`gm_say`），命中别席位未公开的私密文本即拦下并留记录。
