# TABLE.md — 桌面說明（給玩家看的入門；引擎不看）

## 怎麼玩（三行版）

1. 你是其中一個角色，**只看到自己知道的事**（自己的願望、自己手上的碎片、別人向你出示過的）。
2. 每一手宣告一個動作（`move`／`search`／`fight`／`cast`／`pray`／`show`／`give`…），一回合有 2 格行動。
3. 想私下講話就用**私訊**（只有你們兩個看得到）；想讓全桌知道就公開發言。

## 這一桌的目標

| 層次 | 內容 |
|---|---|
| 共同 | 登上百鬼塔的最上階，討伐「百鬼夜行の主」，開那個大祈願箱 |
| 個人 | 每人一條私密願望（カガリ＝帶回折劍的另一半；シズク＝用一次資料寫下十年前的夜） |
| 證據 | 塔裡與城裡的**碎片**；出示給別人看，別人的願望才推得動（出示會留下來源鏈） |

## 場地

- **三座城市**：鉄環市（起點，有闘技場與店）／港町ミナト（塔的**裏口**在這邊）／砦ヤマト（最遠）。
- **百鬼塔 6 階**：1・2 階 骸骨武者 ／ 3 階 補給所（有店）／ 4・5 階 餓鬼・鬼将 ／ 最上階 主 ＋ 大祈願箱。
  - 同一個階的敵人**全滅之前不能上樓**（`ride`）。上樓只能用昇降機。
  - 3 階以下從正面（鉄環市側）出入；**4 階有一個崩掉的出口直通港町側**（`exit_tower`）。
- **荒野道**（`wild`）移動要過檢定；失敗＝停在原地（這一手沒了）。

## 這一桌特有的規則（重要）

- **經驗只從戰鬥來**：升級全靠擊破敵人（階越深，給的越多）。撿東西、聊天、祈願都**不給經驗**。
  （★ 星等是另一回事——那是「劇情條件」給的，跟經驗無關。）
- **死了不會出局**：HP 掉到 0 ⇒ 你被**送回圖上最近的城市**（在哪一階死，送回哪一座城市會不一樣），
  HP 回到 1，並**缺席 2 個自己的回合**（輪到你時引擎會直接跳過，日誌上看得到）。
  人就在那座城市裡——可以說話、私訊、買東西，但**不能出手**，兩回合後恢復。
- **倒地（down）與死亡不同**：被人打倒躺著的人，可以靠同伴的 `rescue`（急救）拉回來；拉回來就不會被送走。
- 塔裡吃東西會扣記憶；出塔時**貨幣會被召し上げられる**（神器不會）。

## 常見問題

- 我的願望怎麼算達成？→ 你的卡上會顯示「還差什麼」（`your_goal.progress`）。
- 我在城市裡能做什麼？→ `rest`（回記憶與 HP）／`buy`（買道具，真的進庫存）／`game`（鉄環市的闘技場）。
- 卡住了怎麼辦？→ 直接問 GM（公開或私訊都行）。
- 死兩次會怎樣？→ 就再被送回來一次；這是這一桌的常態（所以恢復道具與 `rescue` 才是隊友之間的硬通貨）。
