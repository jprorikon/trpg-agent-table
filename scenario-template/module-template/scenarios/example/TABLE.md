# TABLE.md — 桌面說明（給玩家看的入門；引擎不看）

## 怎麼玩（三行版）

1. 你是其中一個角色，**只看到自己知道的事**（自己的願望、自己手上的碎片、別人向你出示過的）。
2. 每一手宣告一個動作（`move`／`search`／`pray`／`show`／`give`…）；檢定與結果由引擎算，GM 只負責描述。
3. 想跟某個人私下講話就用**私訊**（只有你們兩個看得到）；想讓全桌知道就公開發言。

## 常見問題

- 我的願望怎麼算達成？→ 你的卡上會顯示「還差什麼」（`your_goal.progress`）。
- 我可以說謊嗎？→ 可以，但引擎只認你宣告的動作與事實；**碎片一旦出示就留下來源鏈**。
- 卡住了怎麼辦？→ 直接問 GM（公開或私訊都行）。
