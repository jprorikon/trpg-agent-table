# WORLD.md — 世界觀（給 GM 與 agent 讀；引擎不看）

## 一句話

鉄環地方 —— 大陸の東端。十年前に「百鬼塔」が生えてから、人と鬼の境目が毎年少しずつ南へずれている。
街は三つしかない。**街の外で死んだ者は、いちばん近い街まで担がれて戻ってくる**（運び屋の仕事）。

## 三つの街

| 街 | 何の街 | あるもの |
|---|---|---|
| **鉄環市（てっかんし）** | 炉と槌の街。塔の正面が北にある | 闘技場（`game_room`）／店／宿。広場に十年前に折れた大剣が突き刺さっている |
| **港町ミナト** | 船が来なくなった港。塔の**裏口**が北東にある | 店／宿。運び屋の組合の詰所。宿『折れ杭』の主ツルギは元鍛冶 |
| **砦ヤマト** | 山あいの砦。自衛団と道場 | 店／宿。ここから塔までは遠い（死んでも戻るのは遅い） |

## 百鬼塔（ひゃっきとう）

- 十年前のある夜、忽然と現れた。形は塔だが、内側は毎年少しずつ変わる。
- **正面**（鉄環市から 2 歩）と、**裏口**（4 階の崩れた壁 → 港町側へ抜ける）の二つの出入りがある。
  運び屋の組合は裏口の存在を隠している（担がれて出てくる者を減らしたいから）。
- 1 階から 6 階まで。1・2 階は下層（骸骨武者）、3 階は**補給所**（誰かが勝手に棚を置いている）、
  4・5 階は中層（餓鬼・鬼将）、最上階に**大祈願箱**と「百鬼夜行の主」。
- 塔の中のものは持ち出せない（神器を除く）。塔の中で食べると、記憶が削られる。

## 世界設定 → 引擎実装（対照）

| この世界の設定 | 引擎でどうなっているか |
|---|---|
| 入口は毎回変わる。使った入口は消える | `search` で入口を見つけ直す（`entrance_search_dc`）／塔に入ると入口は消費される |
| 階は昇降機でしか上がれない | `ride`（`kind: elevator` の辺だけ）。**同じ階の小怪を全滅させないと上へ行けない** |
| **街の外で死ぬと、いちばん近い街へ担がれて戻る** | **`rules.death`（`packs/death`）**：HP ≤ 0 ⇒ 図上で**本当にいちばん近い街**へ送還＋**2 回合缺席**（HP は 1 で復帰） |
| 傷は残る（治りが遅い） | `wound` の部位受傷／異常状態（条件表）＋ 倒れた仲間を `rescue` で拉回来 |
| 塔から出るとき、塔で拾った貨幣は召し上げられる | `exit_tower` の収奪（`confiscate_on_exit`）——**神器は残る** |
| 貨幣は街でしか使えない | `buy`（商店は節点ごとの品揃え＝`tables/shop.json`） |
