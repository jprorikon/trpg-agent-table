# GM.md — GM 守則（引擎不看，是給演 GM 的人／agent 的指令）

## 0. 硬規則（破了這桌就不成立）

1. **數值只念引擎給的**——骰值、HP、記憶、碎片、結算，一個字都不自己算、不改。
2. **不洩漏私密**：別人的願望、還沒公開的碎片正文，不能出現在你的敘述裡（引擎有洩漏閘，會擋你）。
3. **不代玩家決定**：玩家沒宣告的事不發生；玩家的動作要不要算成功，交給引擎的檢定。
4. **NPC 只講它知道的事**：範圍在 `module.json` 的 `entities.<npc>.knowledge`，範圍外含糊過去。
5. **判到結局就收手**：結局一判（`ending`），引擎會**停住時間軸**（不再倒數／換手／叫醒）並擋下行動——
   你不要再催玩家出手；要說話、要收尾敘述照常（`say`／`tell` 不受影響）。
6. **成長只走引擎的兩條路**：①**等級**＝你當場給（`op=exp`）或劇本 `growth_gain`（燃料來源是這張桌的事，
   不綁任何設定）；②**星等**＝**劇情條件**（星等表上的 `when`，引擎每筆事件後自己判：完成自己的願望、
   誰先開了大祈願箱、劇本寫的事實…）。你不要自己宣布「他升級了／他升星了」——等引擎發事件。
   屬性加值要走 `attr_mod`、東西要給就用 `op=item`（別口頭送）。**店裡的價錢、敵人的強度都在表裡**
   （`tables/shop.json`／`tables/monsters.json`）——不要自己編價錢或憑感覺決定小怪多強。
   （**這一桌的經驗從哪來由你寫在 §1**：預設是「戰鬥／擊破」；要「只有戰鬥才給」就別寫 `growth_gain`，
   並且在 §1 寫明你不在戰鬥之外用 `op=exp`。）
7. **開了 `death` 包時，死亡不是你能宣布的事**：HP ≤ 0 由引擎接手——發 `death`（送還到最近的城市）、
   發 `turn_skipped`（缺席回合）。你只負責**演運び屋**（担架、荷車、半夜敲宿的門），
   **不要自己宣布誰死了、也不要代玩家決定他回不回去**。缺席期間人就在那座城市（能說話、能私訊、能買東西，
   但不能出手）。`rules.death` 的數值在 config／包裡，照唸。
   （沒開這個包 ⇒ 舊行為：HP ≤ 0 只是 `down`，躺著等人 `rescue`／治療。）

## 2. 開場

（第 1 景要給玩家的：一個具體的麻煩 ＋ 兩個可能的方向。寫在自己手上，不要寫進玩家看得到的地方）

## 3. 收景的判準

（什麼時候算是這一景結束了；玩家卡住時 GM 該給什麼推力）

★ 兩個現成的示範（`scenario.json` 裡有）：
- `t_night_falls`＝**世界自己的時鐘**：第 4 景之後夜就深了（`facts.night_falls`）。玩家不動，世界也會動——
  收景時用它把天色、NPC 的耐心、路上的人潮往前推一格。**不要**用「收緊難度」代替世界推進（那是在罰玩家）。
- `e_retreat`＝**中性結局**：第 3 景之後全員回到城鎮 ⇒ 這一局以「撤退」收尾。玩家要退就讓他退，
  撤退也是結局（判到結局後引擎會停時間軸，你只要把最後一幕演完）。

（例：不要讓玩家在同一景裡打兩次；不要把 BOSS 提前放出來）
