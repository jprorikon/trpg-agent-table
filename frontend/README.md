# TRPG 桌 · 前端（`web/index.html`）

人类玩家 + AI agent 同席的半合作跑团桌的**网页端**。页面风格是自订的「情报页」设计系统
（白卡 + 青绿 + 深靛蓝顶栏）。

- **单文件、零构建**：整个前端就是 `web/index.html`（HTML + CSS + 原生 JS，无框架、无 npm、无打包）。
- **只依赖桌引擎的 HTTP API**：见 [`docs/API.md`](docs/API.md)。前端不碰骰子/HP/规则——那是引擎的事。
- **三语**：繁中 / 简中 / 日（右上角切，本机记忆）。
- **主题**：浅色（默认，游戏风格）/ 深色（右上角 ☀☾ 或 `?theme=dark`）。

## 快速开始（不用真桌）

```bash
python3 mock/mock_server.py            # 起本地假桌：http://127.0.0.1:8978/
```
假桌用 `fixtures/*.json`（**已脱敏的真实状态快照**）喂页面，并能接受 `act / say / join / gm` 的 POST
（只回显、不判规则）。改前端时开着它，刷新即见效果。

要接真桌：把 `web/index.html` 指向真桌地址即可（同源部署时 API 路径就是相对的 `/api/...`）：

```bash
# 真桌在 127.0.0.1:8971，页面与 API 同源：
#   浏览器直接打开 http://127.0.0.1:8971/?seat=p1&name=カガリ
# 若要把静态页放到别的域，请把 fetch 的相对路径改成真桌绝对地址（或加反向代理）。
```

## 页面结构（改之前先读）

**桌机（≥980px）＝贴边 HUD**：立绘／场景图铺满整屏，信息贴着四边放：

```
┌ 状态卡（左上）──┬──── 顶栏：HP／记忆／魔力 · 标题 · 副标（剧本名）────┬ 地图 遊び方 账号 ⚙ ┐
│ 其他席位        │              这一景（场景卡，上方置中）                │                   │
│ [只有你|席|私讯] │                                                       │   私讯抽屉（开时） │
│ 留守の間に      │                                                       │                   │
│                 │                                                       │                   │
│ 左下：景区      │   桌上日志 ＋ 发言（下方，能置中就置中）              │ 右下：行动区       │
│ （CTA／地点）   │                                                       │ 大颗「移動」＋N颗  │
└─────────────────┴───────────────────────────────────────────────────────┴───────────────────┘
```

- **几何只由几个变量算**（CSS 末尾「v7 桌机版面」那一段）：`--lstack`（左上那一叠的底，JS `syncLeftStack` 量）、
  `--ctx-w`（左下景区宽）、`--rail-w`（右下行动区宽）、`--log-w`／`--log-x`（日志宽与位置＝两侧让开后剩下的空间）。
  **四块保证互不重叠**；要改位置就改这几个变量，别再加一层 `left:…!important`。
- **行动区一排放几颗由宽度决定**（`renderActs`）：放不下的快捷动作并进「ほか」，不会往左溢出压到日志。
- **手机（<980px）**＝单栏 ＋ 底部固定指令区（`#dock`）；≤600px 时主题／翻译／语言收进顶栏的 ⚙。
- **作品的语汇**（地名、固有名词、「小怪」这类用语）由模组的 `locale.json` 给，见下面约定第 5 条。

- **地图是可收起的浮窗**（右下角 FAB；支持 ＋/−、Ctrl+滚轮、双指缩放、拖动平移，`◎` 定位到自己）。
  **默认收起**，不再遮住「行动」卡。
- **「现在该做」卡**在最上面：只看 `stage / you / you_acted / scene_waiting / turn / throttle`，给一句白话
  （本景你还没出手／已出手等 GM 收景／现在轮到 X／GM 还没开景／旁观者先入座），并附「景」与「额度」的白话说明。
- **玩法说明是大弹窗**，只在顶栏或引导卡点了才开；首次进入由引导卡承担，不再自动弹整屏弹窗。
- 所有字体/间距/圆角/颜色都走 CSS 变量（`:root` 里的 `--fs-* / --sp-* / --rad-* / --accent…`），
  改主题只改变量，不要散写数值。

## 必须守住的约定（改前端时别破）

1. **信息防火墙在服务端**：前端只显示视图给它的东西，**不要**自己拼接/推断他人的私密（愿望、碎片正文、
   密讯）。看到 `you.*` / `your_*` 才显示；`seats` 里没有的东西不要猜。
2. **数值权威在引擎**：前端不得自行计算 HP/记忆/额度结果；只按 `view` 与接口回参渲染。
3. **地图是公开信息**：`/api/map` 的节点与连线可以画；**不要**把 `party` 里 `hidden_floor:true`
   的人显示成具体层数（塔内不暴露层数）。
4. **行动＝发请求，不预判**：先 `POST /api/act`，用返回的 `view` 重绘；错误（额度用完、条件不满足）
   要原样显示给玩家。
5. **三语与主题**：新增文案要进三语字典；颜色/尺寸用变量。
   **作品的语汇不进这支页面**：地名译名、派系／定位／神器名、「小怪」这类世界观用语住**模组 repo 的
   `locale.json`**（入口 `view.table.assets.locale`，见 `docs/API.md` §2.10）；前端字典只放中性字样。
6. **本机记忆只放偏好**：`trpg_seat / trpg_name / trpg_lang / trpg_theme / trpg_mapopen / trpg_howto_seen`。
   `trpg_mapopen` 只认 `"open"`／`"closed"`（更早版本的 `"1"` 一律当收起）；`trpg_howto_seen` 现在表示
   「新手引导看过了」（不再等于「大弹窗弹过了」）。

## 推送即上线（本机桌自动部署）

`main` 分支 **push 之后会自动上线到本机桌**（Gitea push webhook → 本机桥 → 部署脚本）：

1. 拉取远端 → 2. **静态闸**（钩子齐全、标签成对、没有裸 `n(`）→ 3. 备份旧文件 →
4. 覆盖本机 `web/index.html` → 5. 跑三套自测（28/46/85）。

**任何一步不过 → 自动回滚，并回一封信说明哪里挂了。** 页面是每请求读文件的，换文件即生效（不用重启桌）。
所以：**只推你确认过能跑的改动**；不确定就先在 `mock/mock_server.py` 下点一遍。

## 提交方式

- 本仓库由 **協作端 / 设计者**与合作方共同维护；改动直接 push 到 `main` 或开 PR 均可。
- 改完请**自测三件事**：① 无 JS 报错（页面顶部红条不该出现）；② 窄屏（<980px）单列不横滚；
  ③ `mock/mock_server.py` 下四个动作（`move / say / join / 收景前的 act`）都能点通。
- 引擎侧的接口如需新增字段，**先提需求再改**（前端不驱动引擎行为）。
